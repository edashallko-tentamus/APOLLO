# In-House Material Preparation

## Core domain
[[Inventory and Laboratory Resources]]

## Purpose
This capability supports the responsibilities described by the [[Inventory and Laboratory Resources]] core domain. Governs the process of internally preparing mixtures. The result of that process is no longer a separate object type — it is an [[Inventory Lot]] with Chemical Type including "In-house mixture," with Lot# replaced by a system-generated Resource ID and expiration derived from the earliest-expiring component.
