# Resource Consumption

## Core domain
[[Inventory and Laboratory Resources]]

## Purpose
This capability supports the responsibilities described by the [[Inventory and Laboratory Resources]] core domain. Governs how Inventory Lots are consumed when added to test workflows and batches: quantity may go negative but is flagged, not blocked; expiration status blocks the addition outright.
