# Test Procedure

## Definition
Controlled procedural instructions for one Test Version — the actual step-by-step content. Distinct from [[Method]], which is the identity/naming layer (Method Name, SOP Code, SOP Document/Link) referenced when a Test is first created; Test Procedure is the detailed instructions that follow later, at the Test Version stage.
