# Decision - Applying a Project Orders All Its Tests

Applying a [[Project]] to a sample orders every test on its accepted quote; unneeded tests are then cancelled (or analytes removed). This matches re-ordering a package and keeps partial ordering explicit. Tests can also be added one at a time from any accepted quote line.

See [[Ontology Principles]].
