# Decision - CFL Site Time Zone Is Pacific

The CFL [[Laboratory Site]] uses the America/Los_Angeles time zone (Pacific time, including daylight saving). Confirmed by Alex Kiddle; this was an assumption until now. Cutoff times and Day 0 for CFL tests are evaluated in this time zone; see [[TAT Clock Start Rule]]. The CFL holiday list is still a placeholder for the lab to confirm.

See [[Ontology Principles]].
