# Decision - Client Order Renamed Lab Order

Client Order is renamed [[Lab Order]]: the samples a client orders at one time, across any submission channel. 'Work Order' was rejected because [[Maintenance Work Order]] already uses it. A Lab Order can span several Projects because projects are applied per sample. Builds on [[Decision - Client Order Replaces Online Test Request]].

See [[Ontology Principles]].
