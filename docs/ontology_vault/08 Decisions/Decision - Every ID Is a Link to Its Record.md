# Decision - Every ID Is a Link to Its Record

Wherever an ID is listed anywhere in the system (lab order, [[Sample]], client, contact, project and quote version, test, analyte, matrix and so on), it is a hyperlink to that record, so staff can open it in one click and share the link with colleagues. A quote ID on a requested test opens the exact quote version the test is priced from (for example PRJ-00003 v2). Records without a page of their own open their list filtered to that record. This introduced a Sample page. Requested by Alex Kiddle after reviewing slice 2.

See [[Ontology Principles]].
