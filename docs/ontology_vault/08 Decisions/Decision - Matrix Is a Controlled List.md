# Decision - Matrix Is a Controlled List

A sample's [[Matrix]] must be chosen from an administrator-maintained list, not typed free text, so reporting and pricing by matrix stay clean. Names are unique regardless of capitals and are stored with the list's spelling. A matrix in use cannot be renamed; retire it (Inactive) and add a new one. An Inactive matrix cannot be used on new samples, but samples already using it keep it and can still be edited. Seeded list: Powder, Capsule, Tablet, Softgel, Gummy, Liquid, Oil, Tincture, Bar, Snack, Raw Material, Plant Material, Cream or Lotion, Water, Environmental Swab. Built in migration 004.

See [[Ontology Principles]].
