# Decision - OOS Investigations Use a Procedure Matched to the Work

One OOS framework, two procedures. Full Phase I (21 CFR 211) is strict and dedicated for pharma work: analyst, supervisor and QA sections e-signed, enforced re-analysis rules, invalidation only with a documented assignable cause and QA approval. Check and Acknowledge is a short checklist with one reviewer signature for labs outside 21 CFR 211, and doubles as the ISO 17025 nonconforming-work record. Automatic data checks run for both because they cost nothing. The procedure follows the work, not the building: Regulated (GMP) clients always get Full Phase I, otherwise the site default applies, so a GMP client tested at a food lab still gets the strict process. Checklist wording and timelines belong to QA's OOS SOP and are configuration. Open: whether 21 CFR 111 supplement clients need a stricter category.
