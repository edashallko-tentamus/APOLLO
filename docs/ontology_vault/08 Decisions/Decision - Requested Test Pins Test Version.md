# Decision - Requested Test Pins Test Version

A [[Requested Test]] records the [[Test Version]] in effect when it was ordered. Later edits to a test's workflow, formulas or limits create a new version and never change what an existing order means. Pricing is not part of the Test Version; it lives on [[Test Catalog Entry]].

See [[Ontology Principles]].
