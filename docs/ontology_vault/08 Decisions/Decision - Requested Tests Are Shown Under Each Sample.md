# Decision - Requested Tests Are Shown Under Each Sample

On the [[Lab Order]] screen, each [[Sample]]'s [[Requested Test]]s are listed directly under that sample in a panel that can be hidden or shown (per sample, or all at once), instead of one combined list of every test on the order. Each panel is a full data-entry grid ([[Grid Data Entry Standard]]) with the same columns as before, minus the sample: test, quote, analytes, prices, rush tier, rush status, rush fee, TAT, Day 0, due date, status and instructions. Tests are added to a chosen sample from its own panel, or to several ticked samples at once. Requested by Alex Kiddle after reviewing slice 2.

See [[Ontology Principles]].
