# Decision - Retention Threshold Flags, Does Not Block

When [[Retained Quantity]] falls below 20% of Quantity Received, the system flags the [[Sample]] via [[Alert]] and [[Notification]] rather than blocking further [[Aliquot]] creation or testing. Consistent with [[Decision - Inventory May Become Negative]].

See [[Ontology Principles]].
