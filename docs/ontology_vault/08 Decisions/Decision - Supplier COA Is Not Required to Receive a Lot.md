# Decision - Supplier COA Is Not Required to Receive a Lot

Receiving an [[Inventory Lot]] never requires a [[Supplier COA]], for any Chemical Type, including Reference Standard and Microbiological Strain. The COA can be attached at receipt or later; COA on File shows whether one is attached. Resolves the open question in [[Decision - Receive Action and Supplier COA Added]].

See [[Ontology Principles]].
