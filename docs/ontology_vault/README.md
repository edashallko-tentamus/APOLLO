## Open in Obsidian

1. Extract the ZIP.
2. In Obsidian, choose **Open folder as vault**.
3. Select the extracted `LIMS_Ontology_Connected_Vault` folder.
4. Open `00 Home`.
5. Open Graph View.

No community plugin is required for the wiki-link graph. Dataview may be added later for live tables.
